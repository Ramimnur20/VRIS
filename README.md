<h1 align="center">VRIS Bot Template</h1>

###

<h4 align="center">VRIS is a discord bot template to start making your own all-in one discord bot!<br>if you found this project helpful please drop a ⭐</h4>

###

<h2 align="left">Installation</h2>

###

<p align="left">Since Vris is made in discord.py, you need to have Python installed. After that, run pip install -r requirements.txt, and then python bot.py, and you're done!</p>
